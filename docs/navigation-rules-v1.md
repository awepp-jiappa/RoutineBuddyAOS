# Navigation Rules v1

## Parent App Flow

앱 첫 실행
→ Child Profile Screen 이동

Child 저장 완료
→ Routine List Screen 이동

루틴 목록 화면
→ + 버튼 클릭
→ Create Routine Screen 이동

루틴 저장 완료
→ Routine List Screen 이동

루틴 카드 클릭
→ Edit Routine Screen 이동

수정 완료
→ Routine List Screen 이동

---

## Child App Flow

앱 실행
→ Today Routine Screen 이동

task 체크
→ 진행률 업데이트

모든 task 완료
→ Completed Screen 이동

완료 화면 버튼 클릭
→ Today Routine Screen 이동
